# Implementation Plan - Multiple Sound Options

The goal is to allow users to choose from different alarm sounds within the app. I will introduce a settings menu to select between various synthetic sound patterns generated by the `ToneGenerator`.

## User Review Required

> [!IMPORTANT]
> The sound selection will be global for all rooms.
> I will add a "Settings" button to the top dashboard for easy access.

## Proposed Changes

### [Component Name] Android App (MainActivity)

#### [MODIFY] [MainActivity.kt](file:///C:/Users/HP/StudioProjects/PanicButton/app/src/main/java/com/example/panicbutton/MainActivity.kt)
- Define a `SoundType` enum: `MORSE_SOS`, `CONTINUOUS_SIREN`, `FAST_BEEPS`, `PULSE`.
- Add a `selectedSound` state (MutableState) in `MainActivity`.
- Add a "Settings" icon (Gear icon) to the `TopAppBar` in `MainDashboard`.
- Implement a `SoundSettingsDialog` composable that allows selecting a sound from a list.
- Refactor `playSOSLoop` into a generic `playAlarmLoop(soundType: SoundType)` function.
- Implement the patterns for each `SoundType`:
    - `MORSE_SOS`: The current `... --- ...` pattern.
    - `CONTINUOUS_SIREN`: A long, high-pitched tone.
    - `FAST_BEEPS`: Rapid, short beeps.
    - `PULSE`: A rhythmic pulsing tone.

## Verification Plan

### Manual Verification
1.  **Open Settings**: Click the gear icon in the dashboard.
2.  **Switch Sound**: Select "Fast Beeps" and close the dialog.
3.  **Trigger Alarm**: Press the ESP button or the volume button. Verify the sound is now fast beeps.
4.  **Repeat**: Test all sound types to ensure they play correctly and loop until stopped.
5.  **Stop Alarm**: Verify the alarm stops correctly for all sound types.
